# Open release candidate

`rc/1.60.0`: invitations that work where the deployment has no email. An invitation's code admits its registration and grants its role without an emailed code when email is unavailable, and an emailed invitation accepted at the invited address proves it; invitation limits are per inviting account.

One RC is open at a time. This file names its branch (`rc/<version>`, the version it will become, cut from master) and what it is for; feature PRs target that branch. See [branches and CI](docs/ci.md).
